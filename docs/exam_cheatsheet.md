## ⚡ 1. 【全13専門領域統合】 科目B 記述直前キーフレーズ集 (30〜50字採点適合)

IPA 公式採点基準に適合する、30〜50 字での模範解答作成テンプレート構文集です。

### 1.1 🔐 暗号・認証・アクセス制御 (SC / ST / DB)
- **静的 RSA 鍵交換廃止の理由**:
  > 「過去の通信パケットが盗聴された場合、将来秘密鍵が漏洩した際に過去の暗号通信が解読されるのを防ぐため。」(48字)
- **バインド機構 (SQLi 防御) の目的**:
  > 「ユーザー入力値が SQL 構文として解釈されるのを防ぎ、データリテラルとして安全に分離・処理するため。」(46字)

### 1.2 🌐 ネットワーク & 通信境界 (NW / IR)
- **送信ドメイン認証 (SPF/DKIM/DMARC) の役割**:
  > 「送信元ドメインの偽装を検知し、デジタル署名によりメール本文の改ざんの有無を検証・ブロックするため。」(47字)
- **プロキシログの送信元個体識別不可の理由**:
  > 「プロキシサーバーで送信元 IP アドレスが変換され、内部端末の固有 IP アドレスが隠蔽されるため。」(44字)

### 1.3 ☁️ クラウド・IAM・ゼロトラスト (ST / EP)
- **ゼロトラストにおける連続認証の目的**:
  > 「ネットワークの境界内外に関わらず、すべてのアクセス要求に対して継続的な認証と最小権限の認可を行うため。」(48字)

### 1.4 🚨 インシデント対応 & ログ解析 (SM / QA)
- **マルウェア検知時の一次隔離アクション**:
  > 「二次被害の拡大を防ぐため、該当端末を LAN および Wi-Fi ネットワークから物理的・論理的に切り離す。」(46字)

### 1.5 📜 ガバナンス・リスク管理・法規 (AU / STR / EDU)
- **情報セキュリティ監査の独立性確保**:
  > 「被監査部門からの影響や利害関係を排除し、客観的かつ公平な立場から検証・判定を行うため。」(42字)
