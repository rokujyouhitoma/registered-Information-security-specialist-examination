## 🏛️ 2. セキュア技術 & アーキテクチャ個別詳細ライブラリ (ST / SA 重点解説)

試験および実務で特に重要となるセキュア技術 (ST) およびシステムアーキテクチャ (SA) の基幹専門用語に関する1ページ構成の本格詳細ドキュメント：

- 🛡️ **[ゼロトラスト・アーキテクチャ (Zero Trust Architecture)](terms/zero-trust.md)**: NIST SP 800-207 準拠、PEP/PDP 構成図、7大原則、判定ロジック
- 🔒 **[TLS 1.3 (Transport Layer Security 1.3)](terms/tls1_3.md)**: 1-RTT / 0-RTT ハンドシェイク、AEAD 暗号スイート、前方秘匿性 PFS
- 🔑 **[公開鍵インフラストラクチャ (PKI)](terms/pki.md)**: CA/RA/VA 役割構造、X.509 証明書チェーン、CRL/OCSP/Stapling 比較
- 🌐 **[OAuth 2.0 & OpenID Connect (OIDC)](terms/oauth2-oidc.md)**: 認可コードグラント、PKCE 拡張、IDトークン/アクセストークン検証
- ✉️ **[送信ドメイン認証技術 (SPF / DKIM / DMARC)](terms/email-security.md)**: メール成りすまし防御、Header From アライメント、DMARC ポリシー制御
