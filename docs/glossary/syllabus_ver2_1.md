# 情報処理安全確保支援士試験 シラバスVer.2.1 用語辞書

本辞書は、IPA公式シラバス Ver.2.1 (全29小項目) に登場するすべての「用語例・キーワード」（全 272 件）を 100% 完全網羅抽出し、一用語ごとに 100 文字程度のピンポイントで正確な個別定義・役割解説を掲載した専門用語データベースです。

- **解説**: 経営陣が主体となり、組織全体における情報セキュリティ方針の策定や意思決定構造、評価・統制を全社的観点から推進・確立する経営管理の枠組み。

- **シラバス参照**: [1-1 情報セキュリティ方針の策定](../syllabus_detail.md)
