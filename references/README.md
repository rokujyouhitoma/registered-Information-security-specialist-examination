## 📌 管理方針・利用規約
1. **一時ファイル・スクラッチ**:
   - PDF解析用スクリプトや一時テキストデータは `scratch/` ディレクトリで処理し、`references/` に不要な中間ファイルを蓄積しないこと。
2. **相対パス参照**:
   - リポジトリ内から本資料を参照する場合は、`references/<filename>.pdf` の相対パスを使用すること。
