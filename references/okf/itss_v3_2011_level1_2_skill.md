# ITスキル標準 V3 2011 ITスペシャリスト/レベル1-2 スキル定義

## 概要
本ドキュメントは、IPAが定義する「ITスキル標準 (ITSS) V3 2011」におけるITスペシャリストおよびレベル1〜2の共通スキルフレームワークを構造化した OKF ドキュメントです。

## スキル熟達度レベル
- **レベル1**: 最低限必要な基礎知識を有し、指導の下で指示された作業を実行できる。
- **レベル2**: 専門知識・技能の基礎を応用し、自立して限定的な作業を実行できる。
- **レベル3**: 応用的な専門知識・技能を有し、要求された作業を自立して実行できる。
- **レベル4**: 高度の専門知識・技能を有し、自立して作業を完遂し、下位者を指導できる（情報処理安全確保支援士の対象レベル）。
