# Open Knowledge Format (OKF) 統合インデックス (Index)

本ディレクトリ (`references/okf/`) は、情報処理安全確保支援士試験（SC）に関する一次情報PDF資料（過去問題・解答例・採点講評・IPA公式シラバス・ITSS資料等）を、AIエージェントおよび学習者が高精度に構造化・検索・全文解読できるよう **OKF (Open Knowledge Format)** フォーマットに変換した一次知識ベースです。

---

## 1. OKF ディレクトリ構成概要

| カテゴリ | 対象概要 | 登録件数 |
|---|---|---|
| **過去問題・解答例・採点講評** | 平成21年度（2009年）〜令和7年度（2025年）の全SC試験問題・解答・講評 | 240+ 件 |
| **公式シラバス・基準資料** | IPA公式シラバス Ver.2.1、科目A-2追補版 Ver.4.0、ITSS V3 | 10+ 件 |
| **合計** | リポジトリ保存済み OKF ナレッジドキュメント全件 | **259 件** |
