# 要求定義書 (User Requirements Document)

Document ID: `REQ-01-user_requirements`

---

## 1. 概要・背景 (Overview & Background)

### 1.1 ドキュメントの目的
本ドキュメントは、**情報処理安全確保支援士試験（登録セキスぺ）**の合格を目指す受験者、**既に合格した有資格者・登録セキスぺ保持者**の再学習（リカレント学習）、および**試験受験を目指していないもののセキュリティを体系的に学びたい一般学習者・エンジニア**のためのナレッジベース構築プロジェクトにおけるユーザー要求定義を記載します。プロジェクトのビジョン、ターゲットユーザー、解決すべき課題、および提供するコンテンツ・機能の要件を規定します。

### 1.2 背景と解決すべき課題
- **背景**: IPA（情報処理推進機構）により「情報処理安全確保支援士試験」のシラバス（出題範囲）や過去問題は公開されています。また、合格後の登録セキスぺ保持者の知識維持や、受験を目的としないIT従事者がセキュリティの知識体系を学ぶための教材としても非常に価値が高い範囲が設定されています。
- **課題**: シラバスには学習すべきキーワードや範囲のみが並んでおり、各技術の詳細なメカニズム、攻撃手法と防御策の体系的な解説、および午後試験（記述式）で求められる「文字数制限に応じた解答テンプレート・キーフレーズ」が十分に集約されていません。さらに、合格者が最新シラバス改定分を効率的に復習できるリファレンスや、ノンペーパー受験者でも体系立ててセキュリティ全般を自習できるドキュメントが少ない状態です。
- **解決アプローチ**: 公式シラバス（Ver.2.1 および 追補版 Ver.4.0）を基盤として解説文、図解、午後記述式の解答パターン、および技術の最新動向を体系的に整理し、受験者・合格者・一般学習者の誰もが快適に閲覧・検索できる高品質な学習ナレッジベースを提供します。

## 2. ターゲットユーザーおよび想定ユースケース (Target Users & Use Cases)

### ターゲットユーザー
1. **情報処理安全確保支援士試験の受験者**（午前II・午後記述試験の対策を行いたい学習者）
2. **試験合格者・登録セキスぺ保持者**（知識のリフレッシュ、最新シラバス・技術動向の再学習、維持講習等の補助資料として活用したい有資格者）
3. **受験や資格取得を目指していない一般学習者・エンジニア**（体系的かつ網羅的にセキュリティの基礎知識・要素技術・運用概念を独学したい学習者）
4. **実務でセキュリティを担当し始めたエンジニア・セキュリティ担当者**（ネットワーク、Webアプリケーション、インシデント対応の基礎知識を整理したい実務者）
5. **社内セキュリティ教育・スキルアップを目指すIT人材**

### 想定ユースケース
1. **シラバスに沿った体系的インプット学習**:
   - 分野別（暗号、ネットワーク、Web/システム、運用・インシデント・法制度）に整理されたドキュメントを読み、要素技術の仕組みや概念を把握する。
2. **試験受験を前提としない一般的なセキュリティ知識の習得**:
   - 試験受験の有無にかかわらず、IT基盤やWebシステム、インシデントハンドリングに必要な実践的セキュリティ知識をリファレンスとして独学・参照する。
3. **試験合格者・登録セキスぺ保持者の知識アップデート・再学習**:
   - シラバス改定（科目A-2追補版等）や最新セキュリティトレンド（TLS 1.3、FIDO2、ゼロトラスト、NIST SP800最新動向）を復習し、実務や知識アップデート、維持講習対策に活用する。
4. **午後記述試験の解法ロジック・フレーズの習得**:
   - 過去問演習セクションを参照し、「なぜその対策が必要か」「どのように答えるべきか」の記述パターン（30字〜40字の模範解答テンプレート）をインプットする。
5. **一次情報へのアクセスと深掘り**:
   - 公的な一次情報（NIST SP800、IPAガイドライン、RFC等）へのリンク一覧から規格や原文の仕様を確認・検証する。
6. **マルチデバイスでの閲覧・検索**:
   - スマートフォンやPCのブラウザから GitHub Pages（または Markdown ビューア）で閲覧し、検索機能を用いて特定のキーワード（例: `GCM`, `PKCE`, `HttpOnly`, `ライトブロッカ`）を迅速に調べる。

## 3. コンテンツおよび機能の要求定義 (Requirements)

### REQ-01-CNT-01: 公式シラバスへの完全対応と網羅性
- IPA情報処理安全確保支援士試験シラバス（Ver.2.1）および追補版（科目A-2 Ver.4.0）に規定された全重点分野を網羅すること。

### REQ-01-CNT-02: 分野別コンテンツの体系化
- 以下の5分野に分類して解説文・図解を整理すること：
  1. **暗号・認証技術**（共通鍵/公開鍵、PKI、MFA、FIDO2、OAuth 2.0 / OIDC）
  2. **ネットワークセキュリティ**（TCP/IP、TLS 1.3、IPsec、DNSSEC、FW/IDS/IPS/WAF、ゼロトラスト）
  3. **Web・システムセキュリティ**（XSS、SQLi、CSRF、OSコマンド注入、SSRF、セッション管理・Cookie）
  4. **運用・インシデント対応・法制度**（CSIRT/SOC、デジタルフォレンジック、ISMS、個人情報保護法、NIST SP800）
  5. **過去問演習・記述対策**（午後試験の問い方パターン、模範解答作成ロジック、誤答分析ノート）

### REQ-01-CNT-03: 記述式試験（午後試験）対策フレーズの明記
- 各ドキュメントには、単なる用語解説にとどまらず「午後試験（記述式）で問われるキーフレーズ・解答型」を明記すること。

### REQ-01-CNT-04: 一次情報・トレーサビリティの保持
- 参照した公的資料（IPAガイドライン、NIST、RFC）へのリンクおよびファイル管理を `references/` ディレクトリで一元管理すること。

## 4. 可読性およびアクセシビリティ要求 (Accessibility Requirements)

- **Markdown 互換性**: 標準の GitHub Flavored Markdown (GFM) に準拠し、任意の環境で整形表示できること。
- **可読性**: 表、Mermaid ダイアグラム、コードブロック、注意書きアラートを適切に用いて視覚的に理解しやすいレイアウトとすること。
- **マルチデバイス閲覧**: PC、タブレット、スマートフォンいずれの画面幅でも崩れずに閲覧できること。

## 5. 今後のロードマップ (Future Roadmap)

- **過去問題解説の拡充**: 年度別の午後問題の深掘り解説および問題別解法パターンの蓄積。
- **単語帳・クイズ形式コンテンツ**: 午前II試験対策のための重要単語一問一答集の作成。
- **図解イラスト・シーケンス図の追加**: 複雑な認証フロー（OAuth 2.0 PKCE や FIDO2）やハンドシェイク（TLS 1.3）のシーケンス図の拡充。
